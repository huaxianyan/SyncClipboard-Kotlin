本次更新修复系统扩展与同步服务仍保持绑定、但剪贴板回调已经失效时，自动同步无法自行恢复的问题。

## 主要更新

- **确认回调状态**：系统扩展在设备锁定或本地剪贴板变化时确认回调注册状态。
- **低频检查**：增加不唤醒设备的低频回调注册检查，最迟在设备正常运行后的 5 分钟内恢复。
- **幂等注册**：相同回调的重复注册改为幂等操作，不重复记录连接事件或重启实时连接。
- **继续待写文本**：回调恢复后继续处理此前待写入剪贴板的远端文本。

注册检查只使用 SystemUI 主线程 Handler 和本机 Binder，不持有 WakeLock，不设置 Alarm，也不增加网络请求。可从 `v0.1.6` 直接覆盖安装。更新系统扩展后需要重新启动设备，使新版本扩展载入 SystemUI。

回调恢复的判定见 [架构说明的自动同步](https://github.com/huaxianyan/SyncClipboard-Kotlin/blob/v0.1.7/docs/architecture.md#自动同步)。
