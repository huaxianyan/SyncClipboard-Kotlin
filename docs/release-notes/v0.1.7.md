# SyncClipboard Kotlin v0.1.7

本次更新修复系统扩展与同步服务仍保持绑定，但剪贴板回调已经失效时，自动同步无法自行恢复的问题。

## 修复内容

- 系统扩展在设备锁定状态或本地剪贴板变化时确认回调注册状态
- 增加不唤醒设备的低频回调注册检查，最迟在设备正常运行后的 5 分钟内恢复
- 相同回调的重复注册改为幂等操作，不重复记录连接事件或重启实时连接
- 回调恢复后继续处理此前待写入剪贴板的远端文本

注册检查只使用 SystemUI 主线程 Handler 和本机 Binder，不持有 WakeLock、不设置 Alarm，也不会增加网络请求。

## 安装与升级

普通手动同步只需安装：

```text
app-release.apk
```

如需后台自动同步，再安装同一版本的：

```text
system-extension-release.apk
```

可直接覆盖安装，服务器方案、加密凭据、自动同步记录和现有设置会继续保留。主体应用与系统扩展应使用同一版本。更新系统扩展后需要重新启动设备，使新版本扩展载入 SystemUI。

Release 同时提供 `SHA256SUMS`，可用于校验两个 APK 的完整性。
