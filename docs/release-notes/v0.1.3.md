本次更新修复 `v0.1.2` 正式包无法建立 SignalR 实时连接的问题。

## 主要更新

- **修复握手解析**：R8 优化 SignalR 内部协议类型后 Gson 无法解析握手响应，现已保留运行时类型。
- **保留协议字段**：保留 SignalR 握手与 Hub 协议消息的序列化字段名。
- **恢复实时推送**：恢复自动同步的 WebSocket 实时推送，低频 HTTP 补查策略不变。

该问题只影响启用了代码优化的正式包，服务器配置、加密凭据和已保存数据不受影响。可直接覆盖安装，现有设置会继续保留。主体应用与系统扩展应使用同一版本，Release 同时提供 `SHA256SUMS`。

实时通道与补查的关系见 [架构说明的自动同步](https://github.com/huaxianyan/SyncClipboard-Kotlin/blob/v0.1.3/docs/architecture.md#自动同步)。
