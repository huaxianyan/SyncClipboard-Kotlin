# SyncClipboard Kotlin v0.1.3

本次更新修复 `v0.1.2` 正式包无法建立 SignalR 实时连接的问题。

## 修复内容

- 修复 R8 优化 SignalR 内部协议类型后，Gson 无法解析握手响应的问题
- 保留 SignalR 握手和 Hub 协议消息的运行时类型及序列化字段名
- 恢复自动同步的 WebSocket 实时推送；低频 HTTP 补查策略保持不变

该问题只影响启用了代码优化的正式包，服务器配置、加密凭据和已保存数据不受影响。可直接覆盖安装，现有设置会继续保留。

## 安装与升级

普通手动同步只需安装：

```text
app-release.apk
```

如需后台自动同步，再安装同一版本的：

```text
system-extension-release.apk
```

主体应用与系统扩展应使用同一版本。Release 同时提供 `SHA256SUMS`，可用于校验两个 APK 的完整性。
