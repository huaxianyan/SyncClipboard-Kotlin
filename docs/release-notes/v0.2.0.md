本次更新重构「接收暂停期间的云端更新」的判定逻辑，修正自动下载的去重基准，并修掉页面切换时系统导航栏露出内容的问题。主要解决一件事：手机剪贴板被系统清空或被其他内容覆盖之后，以前同步过的那份内容再也同步不回来。

## 主要更新

- **去重基准改为本机剪贴板当前内容**：自动下载过去看「这个哈希我处理过」就跳过写入，而那个字段由上传、下载、归档三条路径共用，不说明剪贴板里现在是什么。现在新增一份本机剪贴板登记值，本地复制上报、写入剪贴板成功、延迟写入重试成功三处都会登记，文本的跳过写入只以它为准。登记值与远端内容一致时跳过写入，并记一条「远端内容与本机剪贴板相同」记录。不一致或拿不到时照常写入。图片与文件没有可读回的本机状态，沿用原来的判断方式。
- **补查改用内容时间判据**：补查路径改用服务端给出的内容时间，判断这份内容是不是本机看不到云端的那段时间里积压的。内容时间早于判定时刻超过 5 秒的文本不写剪贴板，改为存入文本历史。该判据只用于补查。实时推送只由别的设备刚改完云端触发，本身就是内容「刚刚」到达的证据。服务器时钟偏移在循环启动时独立校准，不再与基线互相依赖。
- **同步条件上报补齐**：SystemUI 扩展的 Binder 掉线此前没有计入自动同步的存活条件，重连后会跳过基线，把停机期间云端产生的旧内容写进剪贴板。现在它与锁屏、断网同等对待，掉线时一并清除尚未完成的远端写入。
- **自动同步记录**：新增「远端内容与本机剪贴板相同」记录，跳过的写入不再无声发生。被跳过的陈旧内容会附带内容年龄，例如「15 分钟前的文本未写入剪贴板，已存入历史」。
- **跨进程偏好文件按写入者拆分**：主体应用的主进程与 `:sync` 进程各自持有独立的 SharedPreferences 内存副本，任何一方提交都会用自己那份快照重写整个文件。现在设置文件只由主进程写，运行时状态只由 `:sync` 进程写，只读的一方按文件时间戳重新加载。去重基准和同步点不再被跨进程覆盖抹掉。
- **页面切换不再让内容伸进系统导航栏**：底栏收放时 `Scaffold` 给出的底部内边距会一路收到 0，页面内容随之铺到屏幕最底部，在系统导航栏那一条里露出正文。现在页面容器底部永远留出导航栏的高度，内容槽里另加一条与背景同色的遮蔽。
- **应用图标**：主体应用与系统扩展更换为新的循环箭头图标，背景色 `#B3D3F9`。图标位于两个模块共用的品牌资源目录，一处改动同时生效。

可从 `v0.1.9` 直接覆盖安装。系统扩展的接口和通信协议没有改动，升级主体应用即可，不必重新安装扩展。已安装的服务器方案、加密凭据、同步历史和设置都会保留。如需后台自动同步，请安装同一版本的 `system-extension-release.apk`，更新扩展后重新启动设备。

本版本在 Pixel 10 Pro（Android 16）上完成实机验证。覆盖四项：补查到的陈旧内容只归档不写剪贴板、剪贴板已有该内容时不重复写入、系统扩展掉线后自动恢复，以及页面切换时不再有正文落进系统导航栏。
