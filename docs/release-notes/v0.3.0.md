本次更新把目标平台升到 Android 17，接入系统要求的局域网权限，并统一页面切换的动效。返回手势现在可以跟手预览上一页，点击切页、顶部返回按钮和返回手势共用同一套转场。

## 新功能

- **预测性返回**：返回手势可以跟手预览上一页，松手后接着当前进度播放完，中途取消则滑回原位。此前返回由旧的按键回调直接切换页面，没有任何过渡。手势拖到一半时两页都保持清晰可读，不会出现「两页都很淡」。
- **统一页面转场**：点击切页、顶部返回按钮与返回手势共用一套转场参数，前进与返回的方向由页面层级和次序推导，不会再出现「手势预览和点一下的效果不一样」。
- **Android 17 适配**：目标平台升到 Android 17（API 37），最低支持版本仍是 Android 10。Android 17 起访问局域网需要「附近设备」权限组下的局域网权限，新增了对应的说明弹窗与授权流程。权限只在首页「重新检查」、设置里的「测试连接」和磁贴这些主动操作时申请，启动时不会弹窗。

## 改进

- **边到边与大字号**：设置页的输入框不再被输入法遮挡，磁贴操作页改为可滚动布局，大字号下不再挤压。
- **发布产物命名**：改为「项目名-版本号.apk」，主体为 `SyncClipboard-Kotlin-0.3.0.apk`，系统扩展为 `SyncClipboard-Kotlin-Extension-0.3.0.apk`。

可从 `v0.2.1` 直接覆盖安装，服务器方案、加密凭据、同步历史和设置都会保留。系统扩展的接口没有改动，升级主体应用即可，不必重新安装扩展。
系统扩展已迁移到独立仓库 [SyncClipboard-Kotlin-Extension](https://github.com/huaxianyan/SyncClipboard-Kotlin-Extension)，之后的版本从该仓库的 Releases 获取。两边版本号不再要求一致，主体应用更新后可以继续用原来的扩展。本页仍保留拆分前的 `SyncClipboard-Kotlin-Extension-0.3.0.apk`，此后主体 Release 只提供 `SyncClipboard-Kotlin-<版本号>.apk`。

页面模型、转场参数与返回契约见 [界面导航与动效](https://github.com/huaxianyan/SyncClipboard-Kotlin/blob/v0.3.0/docs/architecture.md#界面导航与动效)，局域网权限的申请时机见 [README 的功能说明](https://github.com/huaxianyan/SyncClipboard-Kotlin/blob/v0.3.0/README.md#功能)。
