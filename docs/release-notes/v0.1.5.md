# SyncClipboard Kotlin v0.1.5

本次更新调整自动同步记录的页面结构，减少首页占用空间。

## 更新内容

- 首页不再直接展开自动同步记录
- 在「自动同步」卡片中新增「查看自动同步记录」入口
- 自动同步记录移至独立次级页面，完整显示最近 7 天内最多 100 条记录
- 次级页面支持顶部返回按钮和 Android 系统返回手势
- 「清除记录」操作移至次级页面

自动同步记录的保留期限、数量上限、脱敏范围和存储方式保持不变。服务器方案、加密凭据、同步记录和现有设置会在覆盖升级后继续保留。

## 安装与升级

普通手动同步只需安装：

```text
app-release.apk
```

如需后台自动同步，再安装同一版本的：

```text
system-extension-release.apk
```

主体应用与系统扩展应使用同一版本。Release 同时提供 `SHA256SUMS`，可用于校验两个 APK 的完整性。
