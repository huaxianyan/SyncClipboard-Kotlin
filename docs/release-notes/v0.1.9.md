# SyncClipboard Kotlin v0.1.9

本次更新修复关闭「接收暂停期间的云端更新」后，锁屏期间的远端文本仍可能在解锁后写入剪贴板的问题，并修复特定网络故障可能导致自动同步进程退出的问题。

## 暂停恢复修复

- SystemUI 扩展在 Binder 调用期间同步检查设备锁定状态并完成剪贴板写入，不再将任务投递到主线程后提前报告成功
- 远端内容真正写入前再次检查设备、网络和自动同步条件
- 关闭「接收暂停期间的云端更新」时，进入锁屏或失去网络条件会清除尚未完成的远端剪贴板写入
- 锁屏期间发生的 Binder 写入失败不会保留到解锁后重试
- 设备正常解锁期间的临时 Binder 故障仍保留原有的有界重试能力

实机验证结果：锁屏期间产生的远端文本不会覆盖手机剪贴板；解锁后新产生的远端文本仍可正常写入。

## 稳定性修复

- 修复恢复基线请求失败后，HTTP 兜底请求再次失败可能抛出未捕获异常的问题
- HTTPS 握手中断、临时断网和服务器不可达现在只会进入错误状态及退避重试，不会终止 `:sync` 进程
- 保持 SignalR WebSocket 为主要通道，HTTP 兜底仍限制为最多每 5 分钟一次

## 安装与升级

普通手动同步只需安装：

```text
app-release.apk
```

如需后台自动同步，再安装同一版本的：

```text
system-extension-release.apk
```

可从 `v0.1.8` 直接覆盖安装，现有服务器方案、加密凭据、同步历史和设置会继续保留。主体应用与系统扩展应使用同一版本。

更新系统扩展后必须重新启动设备，使新版本扩展重新载入 SystemUI。

Release 同时提供 `SHA256SUMS`，可用于校验两个 APK 的完整性。
