# SyncClipboard Kotlin v0.1.1

本次更新完善服务器状态和同步失败提示，帮助用户直接判断问题原因并采取对应操作。

## 更新内容

- 自动同步错误现在区分认证、网络、HTTPS 证书、服务器响应、文件保存和内容校验问题
- 服务器卡片在连接检查失败时显示具体原因和处理建议
- 首页与设置之间切换时不再重复检查服务器
- 重新检查服务器期间保持状态灯、地址、按钮位置和卡片高度稳定
- 快速设置磁贴、Android 分享和手动同步不再显示 HTTP 状态码、请求路径或异常类名
- 分享操作窗口使用「上传分享内容」标题，与剪贴板上传明确区分
- 下载保存、文件读取和压缩包处理失败时提供可执行的恢复建议

## 安装与升级

普通手动同步只需安装：

```text
app-release.apk
```

如需后台自动同步，再安装同一版本的：

```text
system-extension-release.apk
```

可直接覆盖安装 `v0.1.0`。主体应用与系统扩展应使用同一版本；升级主体应用后不需要重新配置服务器或保存目录。

## 当前边界

- 自动上传只支持文本，图片和文件请使用 Android 分享
- Android 分享一次处理一个文件
- 自动接收 `Group` 时保存原始压缩包，不自动解压
- 不提供剪贴板历史页面
