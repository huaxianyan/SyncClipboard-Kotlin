本次更新完善服务器状态与同步失败提示，让用户能直接判断问题原因并采取对应操作。

## 主要更新

- **错误分类**：自动同步错误区分认证、网络、HTTPS 证书、服务器响应、文件保存和内容校验六类问题。
- **服务器卡片**：连接检查失败时显示具体原因和处理建议，重新检查期间保持状态灯、地址、按钮位置和卡片高度稳定。
- **隐藏技术细节**：快速设置磁贴、Android 分享和手动同步不再显示 HTTP 状态码、请求路径或异常类名。
- **区分入口**：分享操作窗口使用「上传分享内容」标题，与剪贴板上传明确区分。
- **可执行建议**：下载保存、文件读取和压缩包处理失败时给出恢复建议。

可从 `v0.1.0` 直接覆盖安装，升级主体应用后不需要重新配置服务器或保存目录。主体应用与系统扩展应使用同一版本。

错误分类与状态呈现的说明见 [架构说明的自动同步](https://github.com/huaxianyan/SyncClipboard-Kotlin/blob/v0.1.1/docs/architecture.md#自动同步)。
