# SyncClipboard Kotlin v0.1.6

本次更新修复一个显示问题：设备解锁时 SystemUI 暂时冻结，自动同步可能持续显示未连接。

## 修复内容

- SystemUI 返回临时 Binder 冻结错误时，不再将扩展误判为永久断开
- 真正的扩展进程死亡仍由 Binder `DeathRecipient` 处理
- 在内存中保留最新一条待写入剪贴板的远端文本
- 按 `1 秒 → 5 秒 → 15 秒 → 30 秒`有界重试剪贴板写入
- 锁屏时停止重试，解锁或扩展重新连接后继续
- 重试成功后补记远端 Hash、下载成功时间和自动同步记录
- 扩展通信失败时显示「系统扩展暂时不可用」，不再显示「原因未知」
- 系统扩展与主体应用共用同一套自适应图标和 Android 13 单色图标

重试过程不会新增网络轮询、WakeLock 或 Alarm，也不会将远端文本写入持久存储。

## 安装与升级

普通手动同步只需安装：

```text
app-release.apk
```

如需后台自动同步，再安装同一版本的：

```text
system-extension-release.apk
```

可直接覆盖安装，服务器方案、加密凭据、自动同步记录和现有设置会继续保留。主体应用与系统扩展应使用同一版本。

Release 同时提供 `SHA256SUMS`，可用于校验两个 APK 的完整性。
