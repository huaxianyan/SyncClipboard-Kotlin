# SyncClipboard Kotlin v0.1.4

本次更新新增可持久保留的自动同步记录，方便观察连接和同步是否长期稳定。

## 更新内容

- 首页新增「自动同步记录」，显示实时连接、系统扩展连接、自动上传、自动接收及失败分类
- 记录在应用或手机重启后继续保留
- 最多保留最近 100 条，超过 7 天的记录自动清理
- 相同的连续连接错误只记录一次，连接恢复后再次发生才生成新记录
- 支持在首页清除全部自动同步记录
- 记录文件读写失败时不影响实际同步

## 隐私范围

自动同步记录只保存时间、事件类型、内容类型和错误分类，不保存以下内容：

- 剪贴板正文
- 服务器地址
- 用户名或密码
- 文件名
- 内容 Hash
- 锁屏和解锁时间

记录保存在应用私有目录，不参与 Android 系统备份。

## 安装与升级

普通手动同步只需安装：

```text
app-release.apk
```

如需后台自动同步，再安装同一版本的：

```text
system-extension-release.apk
```

可直接覆盖安装，服务器方案、加密凭据和现有设置会继续保留。主体应用与系统扩展应使用同一版本。

Release 同时提供 `SHA256SUMS`，可用于校验两个 APK 的完整性。
