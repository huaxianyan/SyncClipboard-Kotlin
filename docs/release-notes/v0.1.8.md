# SyncClipboard Kotlin v0.1.8

本次更新增加可选的加密文本同步历史和暂停恢复策略，并重新整理主体应用的 Material 3 界面、动态配色、导航与交互组件。

## 文本同步历史

- 可在设置中开启「保存文本同步历史」，默认关闭
- 在底部「历史」页面查看来自本机和云端的同步文本
- 支持复制完整文本、删除单条记录和清空全部
- 最近 7 天最多保留 100 条，总文件不超过 10 MB
- 同一服务器、来源和 Hash 连续重复时合并记录
- Android 标记为敏感的自动上传文本不会进入历史
- 图片、文件和 `Group` 内容历史暂未包含在本次更新中

文本历史使用独立的 Android Keystore 密钥和 AES-256-GCM 加密，不与服务器凭据共用密钥。历史文件保存在应用私有目录，并使用跨进程文件锁和原子替换写入。

## 暂停期间的云端更新

新增「接收暂停期间的云端更新」设置，默认开启以保持升级兼容。

关闭后，锁屏、断网或不满足仅 Wi-Fi 条件期间发生的远端更新不会在恢复时覆盖当前剪贴板。恢复过程会将服务器当前内容作为基线；如果文本历史已经开启，这份最新内容仍会保存为「来自云端 · 保存在历史」。基线建立后的新内容继续正常写入剪贴板。

SyncClipboard Server 只保留最新状态。暂停期间发生 `A → B → C` 时，如果 A、B 已被服务器覆盖，手机恢复后只能观察到 C，无法还原 A、B。

## 界面与交互

- Android 12 及以上版本支持 Material You 动态配色
- Android 10 和 Android 11 使用内置浅色／深色回退主题
- 首页、历史、设置和次级页面增加与导航方向一致的过渡动画
- 文本同步历史成为独立底栏页面
- 状态灯和状态文案切换增加平滑过渡
- 开关恢复使用 Material 3 动态主色
- 统一主要操作、辅助操作和删除操作的按钮层级
- 修复进入自动同步记录时底栏收起后页面内容突然跳动的问题

自动同步状态仍使用绿色、黄色、红色和灰色表达运行、等待、错误和关闭，不受壁纸主色影响。

## 稳定性

- 恢复基线只用于真实的锁屏、网络和用户设置暂停，SignalR 技术性重连或 Binder 短暂失败不会静默跳过远端内容
- 服务器凭据加密与文本历史加密共用一套 AES-GCM 实现，但保留各自独立的密钥、AAD 和兼容格式
- 文本历史或诊断记录写入失败不会中断同步

本版本连续实机使用约 4 天。最终测试 APK 安装后未发现崩溃、ANR 或异常后台唤醒；最终扩展在重启并载入 SystemUI 后未再次断开，网络中断后 SignalR 均能自行恢复。

## 安装与升级

普通手动同步只需安装：

```text
app-release.apk
```

如需后台自动同步，再安装同一版本的：

```text
system-extension-release.apk
```

可直接覆盖安装，服务器方案、加密凭据、自动同步记录和现有设置会继续保留。文本同步历史默认关闭，不会因升级自动保存剪贴板正文。

主体应用与系统扩展应使用同一版本。更新系统扩展后需要重新启动设备，使新版本扩展载入 SystemUI。

Release 同时提供 `SHA256SUMS`，可用于校验两个 APK 的完整性。
