# SyncClipboard Kotlin v0.1.2

本次更新加强服务器配置安全，并补齐服务器方案删除与跨进程刷新能力。

## 更新内容

- 使用 Android Keystore 管理的 AES-256-GCM 密钥加密保存完整服务器方案
- 首次启动时自动将旧版明文服务器配置迁移为密文，成功后删除旧明文
- 服务器凭据无法读取时保留原数据，并在首页、设置、自动同步和手动同步入口显示明确提示
- 关闭应用数据系统备份，避免加密配置与设备绑定密钥分离
- 支持在编辑页删除服务器方案，并在删除当前方案后自动选择剩余服务器
- 新增、编辑、切换或删除服务器后，立即通知 `:sync` 进程重新加载配置
- 服务器方案变化时重置自动同步去重基线，避免新服务器漏传已有文本
- 修复 Android Keystore 不允许调用方指定加密 IV 导致的迁移失败

## 安装与升级

普通手动同步只需安装：

```text
app-release.apk
```

如需后台自动同步，再安装同一版本的：

```text
system-extension-release.apk
```

可直接覆盖安装 `v0.1.1`。首次打开主体应用时会自动迁移现有服务器配置，无需重新填写。主体应用与系统扩展应使用同一版本。

从本版本开始，应用配置不再参与 Android 系统备份。应用升级不会删除现有配置；卸载后重新安装或更换设备时需要重新添加服务器和保存目录。

Release 同时提供 `SHA256SUMS`，可用于校验两个 APK 的完整性。

## 当前边界

- 自动上传只支持文本，图片和文件请使用 Android 分享
- Android 分享一次处理一个文件
- 自动接收 `Group` 时保存原始压缩包，不自动解压
- 不提供剪贴板历史页面
