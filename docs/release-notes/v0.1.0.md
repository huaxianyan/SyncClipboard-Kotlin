# SyncClipboard Kotlin v0.1.0

首个公开测试版本，提供原生 Android 手动同步和可选的 LSPosed 后台自动同步。

## 主要功能

- 通过快速设置磁贴上传或下载剪贴板
- 上传和下载文本、图片及单个文件
- 从相册、文件管理器等应用分享内容到 SyncClipboard
- 管理和切换多个服务器方案
- 支持 HTTP Basic Auth、自签名 HTTPS 证书和 SHA-256 校验
- 可选的无界面 LSPosed 系统扩展
- 解锁期间自动上传本地剪贴板文本
- 通过 SignalR 实时接收远端文本、图片和文件
- 图片与文件分别保存到用户选择的目录
- 支持仅通过 Wi-Fi 自动同步
- 锁屏后暂停远端连接，解锁或网络恢复后自动继续
- 首页区分正常运行、预期等待和同步错误

## 安装

普通手动同步只需安装：

```text
app-release.apk
```

如需后台自动同步，再安装：

```text
system-extension-release.apk
```

系统扩展需要支持 libxposed API 102 的 LSPosed 环境，并在 SystemUI 作用域中启用。主体应用与系统扩展应安装同一版本发布的 APK。

## 当前边界

- 自动上传只支持文本，图片和文件请使用 Android 分享
- Android 分享一次处理一个文件
- 自动接收 `Group` 时保存原始压缩包，不自动解压
- 不提供剪贴板历史页面
