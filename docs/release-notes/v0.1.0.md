首个公开测试版本，提供原生 Android 手动同步与可选的 LSPosed 后台自动同步。手动同步无需额外依赖，自动同步需要系统扩展。

## 主要更新

- **手动同步**：通过快速设置磁贴上传或下载剪贴板，也能从相册、文件管理器等应用分享内容到 SyncClipboard。
- **内容类型**：上传与下载支持文本、图片和单个文件，图片与文件保存到用户选择的目录。
- **多服务器方案**：支持管理并切换多个服务器，认证方式包括 HTTP Basic Auth、自签名 HTTPS 证书和 SHA-256 校验。
- **实时接收**：通过 SignalR 实时接收远端文本、图片和文件。
- **自动上传**：解锁期间自动上传本地剪贴板文本，支持仅通过 Wi-Fi 自动同步。
- **锁屏暂停**：锁屏后暂停远端连接，解锁或网络恢复后自动继续。
- **状态呈现**：首页区分正常运行、预期等待和同步错误。
- **图标与布局**：使用支持 Android 13+ 主题图标的极简自适应图标，服务器检查期间保持卡片布局稳定。

该版本自动上传只支持文本，图片和文件请使用 Android 分享，且一次处理一个文件。自动接收 `Group` 时保存原始压缩包，不自动解压。此时还没有剪贴板历史页面。

系统扩展需要支持 libxposed API 102 的 LSPosed 环境，并在 SystemUI 作用域中启用。安装步骤见 [README 的使用方式](https://github.com/huaxianyan/SyncClipboard-Kotlin/blob/v0.1.0/README.md#使用方式)。
