# 架构说明

## 模块

项目由三个 Gradle 模块组成：

| 模块 | 职责 |
| --- | --- |
| `app` | 主体应用，负责界面、配置、协议、网络、文件处理、Hash 校验和同步记录 |
| `bridge-api` | 主体应用与系统扩展共用的 AIDL 接口及协议常量 |
| `system-extension` | 注入 SystemUI 的无界面 LSPosed 扩展，只负责访问系统剪贴板和转发设备锁定状态 |

主体应用是唯一的配置和业务中心。系统扩展不保存服务器配置，不访问网络，也不维护数据库、历史记录或通知。

## 手动同步

快速设置磁贴和 Android 分享使用轻量原生 Activity，不启动 Compose 页面：

```text
SystemUI／Android 分享
→ TileActionActivity
→ ClipboardTransferService
→ SyncClipboardClient
→ SyncClipboard Server
```

上传时先写入数据文件，再更新 `SyncClipboard.json`，避免元数据指向尚未存在的文件。下载时根据内容类型写入剪贴板或系统下载目录。

## 自动同步

高级自动同步由 SystemUI、主体应用的独立进程和服务器共同完成：

```text
本地复制文本
→ SystemUI 扩展
→ Binder
→ 主体 :sync 进程
→ SyncClipboard Server

RemoteProfileChanged
→ 主体 :sync 进程
→ 类型过滤与 Hash 校验
→ SystemUI 剪贴板或 SAF 保存目录
```

自动上传目前只处理文本。图片和文件由 Android 分享入口手动上传。远端图片与文件可以自动接收，并分别写入用户通过 Storage Access Framework 选择的目录。

系统扩展写入远端文本时会抑制对应的本地回调，主体进程还会再次比较 Hash，避免远端内容被反向上传。

## 网络生命周期

远端更新以 SignalR WebSocket 为主要通道，并限制为 WebSockets 传输。连接建立后会立即补查一次远端状态。

运行策略：

- 设备解锁且网络条件满足时连接
- 锁屏后断开连接
- 网络恢复后立即重连
- 连接失败后按 `5 秒 → 15 秒 → 30 秒 → 1 分钟 → 2 分钟 → 5 分钟`退避
- SignalR 不可用时，HTTP 补查最多每 5 分钟执行一次
- 不持有 WakeLock，不设置 Alarm，不使用前台服务
- 开启「仅通过 Wi-Fi 自动同步」后，移动网络期间停止自动上传、SignalR 和 HTTP 补查

Pixel 的息屏显示状态下，屏幕可能仍被系统报告为可交互。因此真实锁定状态由 SystemUI 中的 `KeyguardManager.KeyguardLockedStateListener` 转发，主体进程不依赖普通屏幕广播判断锁屏。

## 待上传文本

自动上传只保留最新一条待处理文本：

- 普通文本保存在应用私有配置中，进程重启后可以恢复
- 新文本会替换旧文本，不建立历史队列
- 上传成功、关闭自动同步或关闭文本自动上传后清除
- 空白文本不进入队列
- 被标记为敏感的内容不写入持久存储

清除操作会比较待处理文本，旧任务完成时不能误删随后复制的新内容。

## 文件处理

手动上传支持文本、图片和单个文件。远端自动接收按元数据中的内容类型过滤，未启用的类型不会请求对应数据文件。

远端图片和文件使用流式下载：

```text
HTTP 响应流
→ 同步计算 SHA-256
→ SAF 输出流
→ 校验成功后保留文件
```

下载或校验失败时删除未完成文件。自动接收 `Group` 时当前保留压缩包；手动下载 `Group` 时执行路径检查、文件数量限制和解压后大小限制。

## IPC 与安全边界

- 系统扩展的静态作用域只有 `com.android.systemui`
- 主体应用与系统扩展使用不同 UID，不使用 `sharedUserId`
- 两个 APK 使用同一发布证书，主体应用会比较安装包签名
- Binder 服务仍会逐次验证调用 UID 对应的包名，同签名不能代替调用方校验
- 桥接协议版本不兼容时拒绝启用高级自动同步
- 文件目录使用 SAF Tree URI 和持久授权，不依赖裸文件系统路径
- 自签名证书信任只对用户明确开启的服务器方案生效
- 服务器方案使用 Android Keystore 管理的 AES-GCM 密钥加密，旧明文配置只用于一次迁移
- 应用数据不参与系统备份，避免加密配置与设备绑定密钥分离

## 状态模型

首页从 `:sync` 进程读取真实运行状态：

- 绿色：自动同步正常运行
- 黄色：等待 Wi-Fi、等待网络、等待解锁或正在连接
- 红色：扩展、服务器凭据、认证、网络、TLS、服务器响应、文件保存或内容校验错误
- 灰色：用户主动关闭自动同步

服务器状态、扩展握手和最近同步时间分别来自真实网络检查、Binder 状态及成功同步记录。手动连接检查与同步核心共用同一套错误分类；同步核心通过 Binder 返回稳定的分类码，界面只负责映射为可操作提示，不依赖异常消息文本判断错误类型。
